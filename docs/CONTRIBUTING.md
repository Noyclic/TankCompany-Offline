# Contributing

Thanks for helping preserve the possibility of an offline tank-battle experience.

## Good contributions

- Reproducible metadata reports from a legally obtained app copy.
- Original code for a standalone local backend or battle simulation.
- Tests, documentation, bug reports and architecture diagrams.
- Original placeholder maps, vehicle definitions and bot behavior.

## Do not contribute

- Copyrighted game assets or extracted proprietary content without redistribution permission.
- Decompiled proprietary source dumps.
- Credentials, tokens, private keys, personal data or private account information.
- Exploits, bypasses or instructions for defeating authentication, anti-cheat, encryption, DRM or access controls.
- Code that targets live publisher infrastructure.

## Pull request checklist

- [ ] Explain the problem and the intended change.
- [ ] Include reproducible steps or tests.
- [ ] Identify any assumptions and their confidence.
- [ ] Confirm that submitted code and assets are original or appropriately licensed.
- [ ] Do not include large binaries or secrets.
